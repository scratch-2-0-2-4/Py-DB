# ✦ Utilisation de l'IA dans le projet

## Outils utilisés
- **Mistral Vibe** (ex *Le Chat*)
- **Gemini**

## Utilisation
- **`acceptlicense.py`** : Code pour vérifier l'acceptation de la license
- **`.license`** : Utilisé par le fichier **`acceptlicense.py`**.
- **Traductions** : L'IA a peut être été utilisé à des fins de traductions.
- **`sync.yml`** : Syncronisation vers GitLab
- **`Makefile`** : `Makefile` 95% généré par IA
- **`*.sh`** : Tous les `.sh` sont 100% généré par IA
- **`SQLite`** : Le **`SQLite`** est principalement fais avec l'IA
- **`relases.py`** : Module généré par l'IA

## Vérification
Tout le code généré par l'IA a été vérifié par des humains.
